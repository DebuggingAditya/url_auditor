#  Website Technical SEO & Health Auditor

A full-stack web tool built to audit web pages for performance, SEO structure, accessibility, and HTTP response metrics.

---

##  Quick Start & Local Setup

### Prerequisites
- Node.js (v18+)
- npm

### 1. Installation
```bash
# Clone repository
git clone <YOUR_GITHUB_REPO_URL>
cd url-auditor

# Install Backend Dependencies
cd backend
npm install

# Install Frontend Dependencies
cd ../frontend
npm install
